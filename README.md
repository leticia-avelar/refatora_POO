# refatora_POO

# Refatoração P1 - Paradigma Orientado a Objetos

Este repositório contém a atividade de refatoração do Trabalho 1 (P1), onde um código originalmente escrito com abordagens dos paradigmas funcional e imperativo foi reescrito utilizando o **Paradigma Orientado a Objetos (POO)** em Python.

##  Sobre o Projeto

O objetivo do script é receber dados de um aluno (nome, idade e três notas), calcular sua média e retornar se ele foi aprovado (média >= 7) ou reprovado. 

Na versão refatorada para POO, foi criada a classe `Aluno`, que encapsula:
- **Atributos:** `nome`, `idade` e `notas` (lista).
- **Métodos:** `calcular_media()`, `verificar_situacao()` e `exibir_informacoes()`.

##  Tecnologias Utilizadas

- PYTHON 3 E VSCODE
